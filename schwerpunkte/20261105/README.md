## 怎么背

先背“目标或结论＋技术原因＋场景后果”。例如Schutzbedarf要说具体损失；报价要说数量、净毛价基础和折扣顺序；WLAN要说速率下降原因、频段差异和安全措施。把中文提示当作理解线索，正式作答尽量使用完整德语句子。

编程和SQL同时用[书面SQL模板](SQL_MUSTER.sql)及PDF末尾算法模板练习。已有[6道编程诊断题与答案](https://github.com/lilarosa/ihk-ap1-prep/tree/main/tasks/programmierung-diagnose-01)仍可配合。
