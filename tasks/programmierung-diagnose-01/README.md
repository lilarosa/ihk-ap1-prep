6 Diagnoseaufgaben für den Einstieg. Stand: 26.10.2026.

- [Aufgaben ohne Lösungen](AUFGABEN.md)
- [Musterlösungen mit Erklärung](LOESUNGEN.md)

先做第 1—4 题，建议 30 分钟。先手写或在空白文档中作答，再看独立答案。第 5—6 题练习完整方法与 CSV。不会时也记录你已经想到的步骤。

Die Aufgaben üben Bedingungen, Schreibtischtest, Schleifen, Rückgabewerte, Durchschnitt und einfache CSV-Verarbeitung. Es sind eigene Übungen zu den zuvor ausgewerteten Aufgabentypen, keine offiziellen Prüfungsaufgaben und keine Vorhersage. [Quellenbasis der bisherigen Sammlung](../../pruefungsfit/bawue-2026-de/QUELLEN.md).

## Java-Beispiele ausführen

Erst nach dem eigenen Versuch:

```sh
java ProgrammierungDiagnose.java
```

Ausführung im Verzeichnis dieser Datei mit einem JDK ab Java 11. Alternativ:

```sh
javac ProgrammierungDiagnose.java
java ProgrammierungDiagnose
```

Die Java-Datei enthält die Lösungen und prüft Normalfälle, Grenzen, leere Arrays und Suchtreffer an verschiedenen Positionen. Sie ist keine leere Aufgabenvorlage.

## Deinen Fehler einordnen

|Wenn du hier hängen bleibst|Dann übst du als Nächstes|
|---|---|
|Aufgabe 1|Bedingungen sowie UND/ODER|
|Aufgabe 2|Variablenwerte nach jeder Schleifenrunde|
|Aufgabe 3|Indexgrenzen, Zähler und Vergleiche|
|Aufgabe 4|Unterschied zwischen Schleife und Methodenende|
|Aufgabe 5|Anforderungen in einzelne Verarbeitungsschritte zerlegen|
|Aufgabe 6|Felder aufteilen, richtige Spalte prüfen und Bedingungen verbinden|

每题标记“独立完成／不确定／不会”。把题号、代码和卡住的地方一起发来，方便针对性批改。
